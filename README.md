🍄 Mushroom Maze
Mushroom Maze is a Java-based maze game featuring maze generation, player navigation, and pathfinding algorithms.

🎮 Features
Interactive maze gameplay
Different maze sizes
Player movement using keyboard controls
Automatic maze solving
Breadth-First Search (BFS)
Depth-First Search (DFS)
Performance comparison and dashboard
Background music and sound effects
🧠 Algorithms
The project implements two pathfinding algorithms:

BFS (Breadth-First Search): Explores the maze level by level to find a path.
DFS (Depth-First Search): Explores one path as far as possible before backtracking.
🛠️ Technologies Used
Java
Java Swing
Eclipse IDE
📁 Project Structure
Algorithms – BFS, DFS, and performance analysis
Assets – Images and visual resources
Entities – Player class
Game – Game screens and interface
Maze – Maze generation and maze logic
Sounds – Music and sound effects
👨‍💻 Project Purpose
This project demonstrates Java programming, graphical user interface development, maze generation, and the practical application of search algorithms.
