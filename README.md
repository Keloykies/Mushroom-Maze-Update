# 🍄 Mushroom Maze

**Mushroom Maze** is a Java-based maze game that combines interactive gameplay, procedural maze generation, and pathfinding algorithms. Players can navigate mazes manually or watch different algorithms solve them automatically.

## 🎮 Features

- Interactive maze gameplay
- Multiple maze sizes
- Keyboard-based player movement
- Automatic maze solving and visualization
- Step-by-step algorithm explanations
- Live algorithm comparison with animated maze visualizations
- Performance dashboard and benchmark analysis
- Ranking system showing 1st, 2nd, and 3rd place based on algorithm completion time
- Background music and sound effects
- Game instructions and user-friendly interface

## 🧠 Algorithms

The project implements three pathfinding algorithms:

- **BFS (Breadth-First Search):** Explores the maze level by level using a queue to find the shortest path in an unweighted maze.
- **DFS (Depth-First Search):** Explores one path as far as possible using a stack before backtracking.
- **A* (A-Star Search):** Uses the distance already traveled and an estimated distance to the goal to guide its search efficiently.

## 📊 Performance Analysis

The project includes an algorithm comparison feature that allows users to observe BFS, DFS, and A* solving the same maze.

It also provides performance measurements and visual comparisons, including:

- Execution time
- Number of visited cells
- Path length
- Memory usage
- Algorithm performance across different maze sizes
